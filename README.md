## 🌟 專案核心特色

### 1. 🌐 即時雙向翻譯與雙向寫作學習系統 (v1.2.0 新增)
- **🇺🇸 寫英文翻中文 (En ➔ Zh)**：英語母語學生可直接輸入英文構思，系統即時轉化為符合大考標準的地道中文作文，並提供**成語修辭升級（Rhetoric Polish）**與注音/拼音標註。
- **🇹🇼 寫中文翻英文 (Zh ➔ En)**：中文母語學生輸入中文作文，系統同步產出具備托福/雅思/SAT 考評等級的優雅英文論述，內建**中式英文校正（Chinglish Detector）**與高級轉折詞提示。
- **🪞 雙向鏡像寫作沙盒 (Mirror Writing Studio)**：左右分欄即時對齊，起承轉合逐段同步翻譯，點擊任意句子即可查看**字詞拆解、近義詞階梯與雙語真人發音朗讀 (TTS)**。
- **📖 離線作文專用對照辭典 (`bilingual_dict.js`)**：內建 500+ 作文核心成語、轉折詞（Transitions）、五感摹寫詞彙與金句，**無網路 100% 離線可用**。

### 2. 🎯 六大身分階梯引導 (K-9 Progression)
- **國小低年級（1~2年級 / Grade 1-2）**：看圖說話、五感探索、短句擴寫、語音輸入（50~150字）
- **國小中年級（3~4年級 / Grade 3-4）**：四素記敘（人事時地）、三/四段起步、譬喻擬人修辭（200~350字）
- **國小高年級（5~6年級 / Grade 5-6）**：立意取材、深層抒情、夾敘夾議、倒敘插敘（400~600字）
- **國中七年級（國一銜接 / Grade 7）**：情境感悟、借景抒情、情節波瀾走勢（500~700字）
- **國中八年級（國二深化 / Grade 8）**：論說三要素（論點/論據/論證）、對比映襯、社會現象（600~800字）
- **國中九年級（會考衝刺 / Grade 9）**：會考六級分標準、圖表非連續文本審題、哲思昇華（700~1000字）

### 3. 💡 「如何寫文章」系統化拆解與術語雙語化
- 審題三步驟（圈題眼、辨文體、立主旨）、起承轉合四段法、論說五段論法。
- 五感觀察放大鏡（視、聽、嗅、味、觸）及 5 大破題法與 4 大收尾昇華法。
- 專門提供英文教學註解（*Qi-Cheng-Zhuan-He*, *Prompt Deconstruction*, *5 Sensory Imagery*）。

### 4. 📚 歷年大考真題與精選題庫庫
- 收錄 103~113 年最新國中教育會考真題（《面對青少年的不滿》、《台灣各世代消費調查》、《多做多得》、《未完成的夢》、《我想開一家這樣的店》等）及基測與國小經典題，附帶英文題意脈絡與寫作金句。

### 5. 📅 30 / 60 / 90 / 180 / 365 天刻意練習計畫
- 依照不同階段提供每日示範任務、每週檢核與連續打卡記錄。

### 6. 📰 即時時事新聞同步思辨
- 涵蓋 AI 進校園、校園手機管理、極端氣候、運動員心理韌性等熱門焦點，自動轉化為正反爭點與分階寫作題目。

### 7. ✍️ 互動沙盒與五維雷達圖評估
- 分段引導寫作（起承轉合逐段提示與即時字數統計）。
- 純本地/離線智能健檢：篇幅完整度、結構組織力、文采修辭、標點規範、立意情感，換算會考 1~6 級分並給出中英雙語改寫建議。

## 🚀 快速上手指南

### 1. 手機端 APP：使用 GitHub Actions 雲端自動編譯 APK
1. 將專案推送到您的 GitHub（可雙擊執行 `push_to_github.bat`）。
2. 進入專案頁面的 **Actions** 標籤頁。
3. 點選 **Build Android APK**，GitHub 雲端會在 2 分鐘內自動編譯。
4. 在執行結果的 **Artifacts** 區塊直接下載 **`WriteMaster-v1.0-Debug-APK`**，解壓縮後傳入 Android 手機即可安裝！

### 2. 手機端免編譯：即時在手機瀏覽器開啟並加到桌面 (PWA)
1. 雙擊執行目錄下的 `start_mobile.bat`。
2. 確保手機與電腦在同一 Wi-Fi 下，用手機瀏覽器開啟畫面顯示的網址（如 `http://10.1.3.14:8080`）。
3. 點擊瀏覽器選單 **「加到主畫面」**（Android Chrome 點右上角選單；iPhone Safari 點下方分享按鈕）。
4. 手機桌面即會產生專屬 APP 圖示，像原生 APP 一樣全螢幕極速運行！

### 3. 電腦端 Web 平台 (Python Streamlit)
1. 進入 `web_platform/` 目錄。
2. 雙擊執行 `start.bat`。
3. 系統會自動檢測環境、安裝必要套件並自動在預設瀏覽器開啟 `http://localhost:8501`。
