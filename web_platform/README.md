## 📖 專案願景與核心特色

在數位資訊爆炸的時代，學生的「文字組織力」、「邏輯思辨力」與「觀察感悟力」是面對未來升學大考（如國中會考、高中學測）與人際表達的最關鍵素養。  
**筆墨思潮 (WriteMaster AI)** 旨在打破傳統「作文題目一出，學生腦袋一片空白」的困境，提供一套具備**身分分級**、**結構拆解**、**大考題庫驗證**、**時事反思**與**階梯式練習計畫**的沉浸式互動 Web 寫作平台。

### 🌟 核心亮點

1. 🎯 **六大身分客製化引導 (K-9 Progression)**
   - 精準對應「國小低年級（1~2年級）」、「國小中年級（3~4年級）」、「國小高年級（5~6年級）」、「國中七年級（國一銜接）」、「國中八年級（國二深化）」與「國中九年級（會考衝刺）」。
   - 各年級皆有專屬的字數規範、重點修辭、引導問題與評閱標準。
2. 💡 **「如何寫文章」系統化拆解**
   - 從審題三步驟（抓題眼、辨文體、立主旨）、五感觀察法、起承轉合四段法到論說文三要素（論點、論據、論證）。
   - 提供 5 大經典破題法與 5 大昇華結尾法，並附有金句與修辭百寶箱。
3. 📚 **歷年大考真題與經典題庫庫**
   - 收錄 103 ~ 113 年最新國中教育會考真題（如：*面對青少年的不滿*、*我想開一家這樣的店*、*未完成的夢*、*青銀共居* 等）。
   - 收錄歷屆國中基測經典題目與國小精選命題，支援題型與年級雙向檢索。
4. 📅 **30 / 60 / 90 / 180 / 365 天循序漸進練習計畫**
   - **30 天考前衝刺**：聚焦審題、段落架構、名言金句、會考評分防踩坑。
   - **60 天奠基穩固**：專注五感描寫、句型擴寫、詞彙多樣化。
   - **90 天進階深化**：掌握記敘、抒情與論說多題型，提煉個人真實事例素材庫。
   - **180 天半年蛻變**：強化批判思考、跨領域閱讀、結構複雜度。
   - **365 天年度成長**：四季主題循環、從生活時事中淬鍊文采，培養一輩子受用的寫作力。
5. 📰 **即時時事新聞同步教學引擎**
   - 自動擷取當前熱門新聞（科技 AI、環境保護、校園文化、社會觀察）。
   - 一鍵將新聞轉化為「背景提要 + 核心爭點 + 延伸引導思維 + 模擬作文題目」，訓練學生從新聞看世界、以筆墨發抒己見。
6. ✍️ **互動式寫作沙盒與智能診斷**
   - 分段引導寫作機制，避免寫出流水帳。
   - 即時字數統計、修辭密度計算、錯別字與冗詞贅字提示、評分雷達圖診斷反饋。
7. 🚀 **純 Python 開發，Windows 一鍵安裝與啟動**
   - 內附 `install.bat` 與 `start.bat`，無需繁瑣設定，點兩下自動架設虛擬環境與啟動 Web 介面。

## 階梯式身分教學架構 (K-9 Matrix)

| 身分階段 | 對應年級 | 建議篇幅 | 學習重點 | 核心訓練模組 |
| :--- | :--- | :--- | :--- | :--- |
| **國小低年級** | 1 ~ 2 年級 | 50 ~ 150 字 | 看圖說話、句型擴寫、五感探索、正確標點 | 句子接龍、感受放大鏡、趣味詞語配對 |
| **國小中年級** | 3 ~ 4 年級 | 200 ~ 350 字 | 人事時地四要素、三段/四段起步、譬喻與擬人修辭 | 事件經過順敘法、童年趣味記敘、自然景物描摹 |
| **國小高年級** | 5 ~ 6 年級 | 400 ~ 600 字 | 立意取材、深層抒情、夾敘夾議起步、倒敘與插敘 | 情感共鳴點、挫折與成長反思、開頭引人入勝法 |
| **國中七年級** | 國一銜接 | 500 ~ 700 字 | 記敘抒情深化、生活情境感悟、借景抒情、情節波瀾 | 告別小學流水帳、主旨提煉、細節特寫鏡頭 |
| **國中八年級** | 國二深化 | 600 ~ 800 字 | 論說文結構、論點/論據/論證、對比映襯、社會現象 | 邏輯論述鏈、名人典故與時事舉例、正反論辯 |
| **國中九年級** | 國三衝刺 | 700 ~ 1000 字 | 會考六級分標準、非連續文本(圖表題)、時間分配策略 | 考場 50 分鐘限時實戰、多角度立體思維、哲思昇華結尾 |

## ⚡ 快速安裝與使用教學

### 方式一：Windows 一鍵安裝與執行（最推薦）

本專案已為 Windows 使用者設計好完全自動化的批次指令檔：

1. **安裝環境**：
   - 雙擊執行目錄下的 `install.bat`。
   - 腳本會自動檢測本機 Python、建立獨立虛擬環境 `.venv`、升級 pip 並自動安裝所有必要套件。
2. **一鍵啟動**：
   - 安裝完成後，雙擊執行 `start.bat`。
   - 系統會自動喚醒虛擬環境、啟動 Web 服務，並在預設瀏覽器中開啟 `http://localhost:8501`。

---

### 方式二：手動終端機安裝（跨平台 Windows / macOS / Linux）

若習慣使用命令列或在非 Windows 系統執行：

```bash
# 1. 進入專案目錄
cd writing_master

# 2. 建立並啟用 Python 虛擬環境
python -m venv .venv

# Windows 啟用方式：
.venv\Scripts\activate
# macOS / Linux 啟用方式：
source .venv/bin/activate

# 3. 安裝依賴套件
pip install -r requirements.txt

# 4. 啟動 Web 應用程式
streamlit run app.py
```

瀏覽器打開 `http://localhost:8501` 即可進入系統。

## 📱 功能特色詳解

### 1. 選擇身分與階梯導航
- 進入系統頂部側邊欄，可自由選擇學習者身分（國小低/中/高，國中七/八/九）。
- 介面自動根據所選身分切換合適的**字數標籤**、**引導提示難易度**與**推薦課題**。

### 2. 「如何寫文章」核心技法庫
- **審題工作法**：學會圈選關鍵字、判斷命題限制、挖掘隱含意義。
- **五感摹寫教室**：視覺、聽覺、嗅覺、味覺、觸覺的全方位描寫示範與例句。
- **經典文章骨架**：
  - *四段起承轉合*：起（破題引導）➔ 承（深化鋪陳）➔ 轉（情節波折/對比）➔ 合（總結啟發）。
  - *論說五段論法*：破題立論 ➔ 正面舉例 ➔ 反面辨析 ➔ 現實映照 ➔ 總結呼籲。
- **破題與結尾錦囊**：提供開門見山法、名言破題法、景物襯托法、首尾呼應法等經典句型。

### 3. 歷年大考題庫與六級分評析
- 收錄 103~113 年國中會考完整題目：
  - `113年`: 面對青少年的不滿
  - `112年`: 台灣各世代民眾日常消費調查（圖表非連續文本）
  - `111年`: 多做多得
  - `110年`: 未完成的夢
  - `109年`: 我想開一家這樣的店
  - `108年`: 青銀共居
  - `107年`: 我們這個世代
  - `106年`: 在這樣的傳統習俗裡，我看見…
  - `105年`: 從那件事中，我發現了幸福
  - `104年`: 捨不得
  - `103年`: 面對未來，我應該具備的能力
- 每一題皆附有**審題引導**、**立意取材建議**、**寫作結構示範**與**歷屆評分要點**。

### 4. 階梯練習計畫 (30 / 60 / 90 / 180 / 365 天)
- **30 天會考/段考快速衝刺**：每日一練習（審題速記、修辭單練、考前模擬），適合最後一個月抱佛腳。
- **60 天寫作基石奠基**：著重語感培養與片段練習，每天 15 分鐘建立自信。
- **90 天思維與文筆進階**：突破瓶頸，掌握議論與抒情雙重切換，建立個人事例庫。
- **180 天半年躍進成長**：結合深度閱讀，訓練長文組織與批判思維。
- **365 天年度大師培育**：四季主題循環，全方位奠定一生的文字影響力。
- 支援**每日打卡紀錄**與**階段性寫作里程碑**，視覺化呈現學習累積。

### 5. 時事新聞同步教學引擎
- 即時擷取最新時事（環境變遷、AI人工智慧、社群媒體現象、體育精神、社會共融）。
- 自動將新聞內容提煉為寫作訓練：
  - **新聞摘要**：孩子在 1 分鐘內掌握事件重點。
  - **思辨爭點**：提出啟發性問題，例如「AI 是否會取代人類的創造力？」。
  - **分階練習題**：為國小與國中生分別設計專屬題目與引導大綱。

### 6. 互動教學與寫作沙盒
- **分段沉浸式寫作**：依照結構分段填寫，系統即時提示本段寫作重點與詞庫。
- **智能文章健檢診斷**：
  - 字數達標檢驗與閱讀時長分析。
  - 修辭手法多樣性分析（排比、譬喻、設問等檢測）。
  - 段落平衡性評估（避免頭重腳輕或虎頭蛇尾）。
  - 即時產出專屬評分雷達圖與具體的優化改進建議。

## 📋 依賴環境與套件說明

- **Python**: 3.9 或更高版本（支援 Python 3.10、3.11、3.12、3.14）
- **主要套件依賴**:
  - `streamlit`: 現代化響應式 Web 應用程式框架。
  - `pandas`: 數據處理與結構化呈現。
  - `plotly`: 視覺化診斷圖表與雷達分析圖。
  - `beautifulsoup4` & `requests`: 網頁內容抓取與資訊處理。
  - `feedparser`: 即時新聞 RSS 解析引擎。

## 💡 常見問題 (FAQ)

**Q1：需要連網才能使用嗎？**  
A1：不需要！系統內建完整的離線歷年大考題庫、分階技巧庫、所有 30~365 天計畫以及精選時事範例資料庫。即使在無網路環境下，核心教學與寫作診斷均可 100% 正常運作。連網時則可額外抓取最新在線新聞 RSS。

**Q2：寫作診斷需要花費 OpenAI 或第三方 API 費用嗎？**  
A2：系統內建高效能的本地規則與語意診斷演算法，包含修辭辨識、詞性豐富度、段落比例檢測與錯別字校對，**完全免費且免 API Key**。系統亦預留可自由外接 LLM（如 Gemini API / OpenAI API）的擴充插槽。

**Q3：可以用於學校班級教學或自學嗎？**  
A3：非常適合！老師可將題目投影於課堂進行分段教學，學生亦可在電腦教室或個人電腦上一鍵執行，依照選定的計畫天數打卡寫作。
